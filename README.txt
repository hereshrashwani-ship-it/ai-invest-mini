AI Invest Mini – gratis statisk PWA-prototyp.
Öppna index.html lokalt på datorn för att testa.
För installation som app på iPhone: publicera mappen via HTTPS, öppna i Safari, välj Dela > Lägg till på hemskärmen.
Rapporter och innehav sparas endast lokalt i den aktuella webbläsaren (localStorage). Ingen synk, ingen inloggning, ingen Avanza-koppling, inga livekurser eller aktiva agenter.
Publicera exempelvis på GitHub Pages eller Netlify. Ingen API-nyckel behövs.
